# Personal Portfolio — 2023

An earlier personal portfolio created during my Full Stack Web Development training. This repository is kept as a record of my learning and work at the time.

**[View the live website](https://portfolio-pedro-barros.vercel.app/)**

## Technology

This project uses Next.js 13, React, TypeScript, Tailwind CSS, and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).
